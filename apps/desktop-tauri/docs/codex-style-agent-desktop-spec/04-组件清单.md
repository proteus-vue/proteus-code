# 04 组件清单

按区域列出必备组件。功能项来自三家实测的功能模块对照（Codex 有、MiMo 全有的：Automations / Artifacts / Worktree / Approval / Sandbox / Composer / Review / Skills / MCP）。

---

## 4.1 Sidebar

| 组件 | 功能要求 | 验收点 |
| --- | --- | --- |
| 会话列表项 | 标题（自动摘要）、时间、状态徽标（运行中/已完成/已中断） | 长标题省略；运行中会话有可见指示 |
| 会话操作 | 重命名、删除、置顶、复制会话 ID、导出 | 删除需二次确认 |
| 搜索 | 按标题与内容全文搜索 | 结果可跳转到具体消息 |
| 项目/仓库切换 | 切换工作目录，显示 git 分支 | 切换后工具栏分支同步更新 |
| 分组 | 按项目 / 按日期分组 | 折叠状态持久化 |
| 折叠态 | 折叠为 62px 图标栏 | 折叠状态持久化 |

## 4.2 Toolbar

| 组件 | 功能要求 |
| --- | --- |
| 模型选择器 | 显示当前模型，可切换；标注每个模型的能力差异（上下文长度、是否支持视觉） |
| 工作区指示 | 当前目录（缩写显示全路径 tooltip）+ git 分支 |
| 权限模式 | 显式档位切换（见 `05` 第 6 条），当前档位始终可见 |
| 上下文余量 | 已用 / 总量，接近上限变色 |
| 设置入口 | |

## 4.3 Message stream

| 组件 | 功能要求 | 验收点 |
| --- | --- | --- |
| 用户消息 | 纯文本 + 附件缩略图；可编辑并重新生成 | 编辑后从该点重跑 |
| 助手消息 | Markdown（含表格、代码块、数学公式、Mermaid 图） | XSS 已净化 |
| 工具调用卡片 | 默认折叠：图标 + 工具名 + 关键参数一行；展开显示完整输入/输出 | 长输出可折叠、可复制、可另存 |
| Diff 视图 | 文件级列表 + 内联/分栏切换 + 逐文件接受/拒绝 | 新增绿 / 删除红 |
| 审批请求 | 显示将要执行什么、影响范围；允许/拒绝/始终允许 | 拒绝后必须真的停止（见 `05` 第 7 条） |
| 错误与重试 | 错误独立样式，可重试单步 | 不把错误混进正文 |
| 分支/回退 | 从任意历史点分叉出新会话（MiMo 有 `ForkRow` `[M]`） | 分叉后原会话不受影响 |
| 思考过程 | 可折叠的推理区（若有） | 默认折叠 |

## 4.5 Composer

| 组件 | 功能要求 |
| --- | --- |
| 输入框 | 多行自适应高度、历史记录（↑ 键回溯） |
| @ 引用 | 引用文件/目录/符号，弹出模糊搜索 |

---

## 4.8 组件实现的两条原则

1. **默认折叠，按需展开。** 工具调用、思考过程、长输出——默认都收起来。信息密度是这类产品的核心体验。
2. **每个破坏性操作都要能撤销或二次确认。** 删除会话、接受全部 diff、覆盖文件——一个都不要漏。
