## 8.3 常见返工点

按踩坑概率排序，提前注意：

1. **被取消的 tool_call 忘记补占位消息** —— chat completions 方言下会直接报错，且症状很迷惑（表现为"模型突然胡言乱语"）。
2. **`maxSteps` 默认 Infinity** —— 直到第一次死循环才发现。
3. **Markdown 不净化** —— 模型输出直接进 DOM。
4. **权限拒绝后循环不停** —— 用户只能点停止，体感极差。
5. **env 白名单透传** —— 外部注入的配置永远不生效，排查很久才发现。
6. **工具输出不截断** —— 一个 `cat` 大文件就把上下文撑爆。
