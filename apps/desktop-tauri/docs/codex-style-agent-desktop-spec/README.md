# Codex 风格 AI 编程桌面端 —— 实现方案包

给 LLM 的执行总纲。**先读完这个文件，再按编号顺序读其余文档。**

---

## 0. 这个包是什么

从本机三个真实产品解包测量得到的一套**实现规范**：

| 来源 | 版本 | 提取范围 |
| --- | --- | --- |
| `Codex.app`（OpenAI） | 26.901.51231 | 前端主 CSS/JS（asar 296MB → 8930 文件） |
| `Xiaomi MiMo.app` | 26.922.220226 | 全量解包（`app.asar` + 引擎 36MB） |
| `ZCode.app` | 3.14.1 | 前端主 chunk + 主 CSS |

包里所有**尺寸、色值、结构、阈值**都是实测值，不是估算。文档中的表格会标注来源，方便你判断该取哪一家的做法。

## 0.1 合规红线（必须先读）

- 本包**只包含事实性测量数据**（数值、结构、术语、阈值）和规范条文。
- 包内**不包含**任何第三方的源代码、CSS、图标、字体、图片或其他受版权保护的资源文件。
- 实现时请**自己写代码**。可以对齐视觉结果（同样的侧栏宽度、同样的圆角、同样的交互流程），但不要复制粘贴他人的 CSS/JS 或搬运其图标字体资源。
- 涉及品牌名、商标、吉祥物形象的部分一律不要模仿。

## 0.3 给 LLM 的执行指令

1. **先做骨架，再做皮肤。** 按 `08` 的 P0→P4 顺序推进，不要一上来就调色。
2. **`05-Agent内核护栏规范.md` 是硬约束，不是建议。** 里面每一条都对应一次真实的线上事故（无限循环、整批工具调用被取消、权限闸门失效）。跳过任何一条都会复现事故。
3. **令牌直接引用。** `tokens.css` 里的变量可以直接复制到你的项目里用，已经按 Tailwind v4 的 `@theme` 组织好。
4. **验收用 checklist。** `08` 末尾有 self-check 清单，实现完逐条打勾，不允许"应该没问题"。
5. **不确定时选保守值。** 拿不准的阈值（并发数、步数上限、超时）取文档中偏小的那个，宁可保守。

## 0.4 一句话说清目标形态

> 一个 Electron 桌面应用：左侧会话/项目列表，中间对话流（含工具调用卡片与 diff），右侧或下方是可拖拽的 diff / 终端 / 预览面板，底部常驻输入框；背后跑一个带完整护栏的 Agent 引擎；全程本地优先，不外传代码。

```
┌────────┬──────────────────────────────┬─────────────┐
│ Sidebar│  Toolbar (46px)              │             │
│  256px │──────────────────────────────│   Panel     │
│        │  Message stream (max 40rem)  │  (resizable)│
│ 会话   │                              │             │
│ 项目   │                              │  diff/终端  │
│        │──────────────────────────────│             │
│        │  Composer (输入框 + 模式选择) │             │
└────────┴──────────────────────────────┴─────────────┘
```
