D12 内置浏览器：文件预览（点文件看内容，引用成为独立动作）

D12 第二层：**内置浏览器（文件内容预览）**。

- **`neo-platform::file_index::preview_file`**：有界、且**限定在工作区内**的读取。
  三种形态各自如实呈现 —— 文本（逐行 + 行号）/ **二进制**（识别 NUL，不当文本
  渲染成乱码）/ 读不出来（给原因）。非 UTF-8 用 lossy 转换（"能看个大概"好过
  整个文件打不开）；单行长度封顶防一行几 MB 的压缩文件。
- **gpui 宿主**：面板改为两栏（文件列表 + 预览栏）。**点击文件 = 预览**，
  "加入引用"成为预览栏里的**独立按钮** —— 此前点击只有加引用，意味着"想看内容
  只能先把整个文件注入模型上下文"，既花钱又绕。
- 新增 `NEO_GUI_PREVIEW=<相对路径>` 启动钩子（与 `NEO_GUI_PANEL` 同族）：
  自绘预览栏收不到合成输入时，脚本化截图验证需要这个入口。

**安全边界**：预览不走沙箱（内容只给人看、不进模型上下文），但必须自己限定
工作区。**两道独立的闸**（实测确认：关掉 `is_within` 时只有软链那条测试会红）：
输入含 `..`/绝对路径由入口检查拦；看起来正常的 `link/secret.txt` 只有
canonicalize 后比前缀才拦得住。`is_within` 在 L1 本地实现（L3 的
`neo-sandbox-local` 那份不能向上依赖，否则违反架构守卫）。

**长行裁切连踩四次才对**（真机截图发现的，前三版都越界）：
1. 抄 diff 正文的 `whitespace_nowrap` → 长行横向冲出面板、盖到主界面；
2. 改折行 → 仍越界（一长串无空白字符**没有折行断点**）；
3. 误用 `text_ellipsis()` → 它**只设样式**、不含 `overflow_hidden`；
4. `truncate()`（三者合一）**加上整条 flex 链的 `min_w(0)`** → 成功。
   flex item 的 `min-width` 默认是 `auto`，不给 `min_w(0)` 则 `flex_1` 的
   "可收缩"形同虚设，`overflow_hidden` 无从裁起。
   客观验证：长行最右像素落在面板右边界（1879 = 940 逻辑点 × 2）。

顺带把数据层的"已截断"标注文字去掉 —— 实测它会被省略号裁在可视区外，是死重。
**数据层管封顶、渲染层管提示**，各做各的不重复。

真机验证（`NEO_GUI_PREVIEW` + 按窗口 ID 截图，全程未抢焦点）：文本逐行带行号、
二进制显示"6 字节 不按文本显示"、长行以 `…` 在面板边界处裁切。
