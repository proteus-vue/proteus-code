Web / 桌面宿主端点加访问令牌；同步 L5 规格漂移

**破坏性（对程序化客户端）**：`neo serve` / `neo desktop` 的 `/api/*` 端点现在都需要
访问令牌，裸 curl 调用会得到 401。用启动时打印的完整 URL（`#token=…`）打开页面即可，
或显式带上 `?token=` / `X-Neo-Token` 头。

为什么是必要的：只绑 `127.0.0.1` 限制的是网络来源、不是谁能访问。本机任意进程都能枚举
回环端口；更现实的是浏览器里的任意网页 —— 端点全是简单请求（不触发 CORS 预检），
恶意页面可跨源 `POST /api/turn` 且**请求会生效**（CSRF）。令牌把这两条同时堵死。

其它改动：
- `--addr` 绑非回环地址时显式警告（令牌拦得住未授权调用，但流量是明文 HTTP）。
- 同步 `L5-host.md` 的两处规格漂移：桌面实际是"开回环端口复用 Web 宿主"（非自定义协议
  不开端口）；`neo-host-web` 实际是"手写 HTTP + SSE"（非 axum + WebSocket）。
