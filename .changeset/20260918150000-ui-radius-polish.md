自绘 UI 精细度第一步：渲染缝支持圆角 + 文件列表行改为真正的列表项

用户反馈"自绘组件 UI 比较粗糙、不到直接上生产的标准"。先审计出**可核对的具体项**，
再改收益最大的两处。

**审计结论（客观可查，不是印象）**：
| 项 | 实测 |
|---|---|
| 圆角 | 渲染缝的 `Op` **没有半径概念**，后端一律 `Corners::default()`（= 全零直角）—— 所有自绘元素都是硬边 |
| 悬停反馈 | 宿主 22 个 `on_click` 元素，`hover(` 出现 **0 次** —— "能点"却看不出能点 |
| 字号层级 | `font_weight` / `text_size` 出现 **0 次** —— 标题与正文同字号，没有信息层次 |
| 列表项形态 | 文件行是裸文字：贴面板边缘、无内边距、无行高、无选中/悬停态 |

**本轮改的两处**：

1. **渲染缝支持圆角**（`Op::FillRect/StrokeRect` 增 `radius`，两个后端都如实传达；
   SVG 导出写 `rx`）。半径**由调用方从设计系统取**（`neo_ui::RADIUS = 6.0`，即
   主题 `radius` medium），不在渲染层写死 —— 与颜色同一条路径。
   **默认 0（直角）是刻意的**：diff 底色带那种整行通铺的面必须直角
   （圆角会让相邻行之间出现缝隙，看起来像"改动行数不对"）。
   组件各自选择：进度段圆角、用量柱顶圆角、变更条与 diff 底带直角；
   圆角一律**先夹到半宽/半高**再入场景 —— gpui 自己夹、SVG 不夹，
   在场景里夹一次才能保证两个后端结果一致。

2. **文件列表行改为真正的列表项**：内边距 + 行高 + 选中底色 + 悬停底色
   （悬停取值跟设计系统的习惯走 `muted` 半透明，不另挑颜色）。

新增两条跨后端契约：半径必须**逐一相同**地传达（且断言"真实场景里确实出现过
非零半径"，否则是在测全 0）、SVG 必须写出 `rx`。牙齿已验证（丢掉半径→红）。
