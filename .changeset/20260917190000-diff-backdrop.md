自绘 diff 行背景带：补上"改动落在哪几段"的形状（渲染缝第 4 个消费者）

两个 GUI 宿主的 diff 正文此前都是**逐行彩色文字**（绿字=新增、红字=删除），
但底色与其它内容一样。逐行彩色只标注了单行语义，给不出"改动落在哪几段"的形状 ——
而看 diff 的第一个问题恰是那个形状。真实 diff 查看器（GitHub / Zed / ZCode）
都有**行背景带**，这是让 diff 能扫读的关键层。新增 `neo-ui-render::diff_backdrop`
（P2 自绘 DiffView 的第一层），gpui 宿主接上。

分工是**缝画底、宿主画字**：底带是矩形填充（缝的强项），文字留在 element 树
（保住 gpui 的文本整形、字形缓存与 element diff）。对齐**由构造保证**而非调间距 ——
底带的 y 用 `i * lh`、文本容器设 `.line_height(lh)` 且每行 `whitespace_nowrap()`，
`lh` 取自 `Window::line_height()`，两边同源。

真机验证（按窗口 ID 截图，不抢焦点）：红底带 130pt 覆盖 5 个删除行 = 每行 26pt，
与行高一致；hunk 头淡蓝、新增行绿、上下文行无底。

7 条单测钉住对齐契约（第 i 条带子落在 `[i*lh,(i+1)*lh)`）、上下文行不画也不占位、
三色可区分且 alpha<128（不抢文字对比度）、裁剪配平且裁到自身总高、5000 行仍线性。
该场景已进 conformance 的跨后端用例集。
