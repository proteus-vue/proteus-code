neo-host-egui 端到端用例：验 UI 卡片别拿"平台相关的沙箱能力"当前提

`tool_cards_carry_name_args_and_output` 用 `ExecMode::Default`（→ 沙箱档
`WorkspaceWrite`）真的跑 `bash echo`。而 `LocalSandbox` 的受限档在 Linux 上
fail-closed（尚无 Landlock+bwrap 实现，拒绝执行），于是该用例在 Linux CI 上
稳定失败 —— 命令根本不执行，`exit_code` 是 -1 而非 0。

这正是 Linux CI 长期红的**唯一**失败用例（已用"临时把 `supports()` 的受限档
改成 false"在本机复现：1 failed / 5 passed，`Some(-1)` vs `Some(0)`）。

修法是改用三平台都支持的 `FullAccess` 档（沙箱档 `DangerFullAccess` 恒可用），
而不是跳过 Linux —— 用例的主语是界面数据通路（名字/参数/输出），与沙箱档位无关。
用 `Default` 档的其它用例（如审批前 diff）不受影响：它们在**执行前**就挂起审批。
