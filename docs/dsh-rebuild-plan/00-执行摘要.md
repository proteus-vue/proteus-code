# 执行摘要（一页纸）

## 目标
重构 DSH，产出 **NEO**：Rust 内核 + Web/TUI 双宿主的编程 Agent。

## 吸收什么

### 来自 智谱 ZCode（交互层，主体闭源，只借鉴可观测的交互范式）
| 设计 | 为什么值得抄 |
|---|---|
| **Goal Mode**（`/goal`） | 把"一次一提示"升级为"持久化目标"：自动拆解子任务 → 执行 → 自验证 → 迭代；可暂停/重定向/断点恢复，不重置会话 |
| **五种执行模式** | 默认 / 变更前确认 / 自动编辑 / 计划模式 / 完全访问。核心逻辑：**自主程度与信任度正相关** |
| **`@` `#` `/` `$` 引用体系** | `@`文件、`#`历史会话、`/`命令、`$`技能 —— 把"上下文装配"从模型猜变成用户显式指定 |
| **任务线程化** | 多个 Goal 并发，各自独立进度面板（耗时 / token / 迭代数） |
| **AGENTS.md 项目约定** | 项目级指令文件，团队共享 |

### 来自 OpenAI Codex CLI（架构层，Apache-2.0，可对照实现）
| 设计 | 为什么值得抄 |
|---|---|
| **多宿主共享内核** | 一份 core 服务 CLI / TUI / Exec / App-Server / MCP —— NEO 取 Web + TUI + Exec |
| **SQ / EQ 事件队列** | `submit(Op)` 与 `next_event()->EventMsg` 解耦宿主与引擎；天然可录制、可回放、可审计 |
| **沙箱 × 审批 正交双轴** | 3 档沙箱（read-only / workspace-write / danger-full-access）× 4 档审批（untrusted / on-request / on-failure / never） |
| **OS 级沙箱** | macOS Seatbelt、Linux Landlock+bwrap+seccomp、Windows restricted token+ACL |
| **Shell-First 工具哲学** | 一个 bash 执行器替代数百专用工具；文件变更只走 `apply_patch` 专用信封 |
| **四级配置 + AGENTS.md 级联** | 内置 → 系统 → 用户 → 项目 → CLI flag |

## 摒弃什么（DSH 的冗余过重设计）

| # | 摒弃项 | 理由 |
|---|---|---|
| 1 | **"一切皆插件"（含 agent loop / UI / 存储插件化）** | 调用栈过深、错误定位极难，是 AI 辅助开发的最大阻碍 |
| 2 | **219 个 workspace 包** | 粒度失控，改一处跨 N 包，构建与认知成本双高 |
| 3 | **100+ 插件默认全量加载** | 冷启动与配置面巨大 |
| 4 | **4 种预制运行模式**（Standard/PTC/Minimal/Creator） | 模式 = 插件集的笛卡尔组合，边界模糊、能力重叠 |
| 5 | **vendor Cordis 9 个包 + 18 条本地修改** | 与上游 Cordis 脱钩，长期维护债 |
| 6 | **社区 Electron 桌面壳** | 78MB+ 包体，进程/端口/托盘全是胶水，与 Node 内核重复 |
| 7 | **PTC 模式的额外 TS 脚本运行时** | 与沙箱叠加，复杂度不成比例 |

## 替换成什么

```
摒弃"一切皆插件"  →  固定六层内核 + 4 类有限扩展点
摒弃 4 种运行模式 →  正交双轴：5 档执行模式 × 3 档沙箱（UI 档位映射到审批策略）
摒弃 Electron 壳  →  Web 宿主（Axum+WS）+ TUI 宿主（ratatui）
摒弃 219 包       →  12 个 crate，依赖严格单向
```

## 里程碑（详见 04）

| 阶段 | 交付 | 关键验收 |
|---|---|---|
| M0 | 内核骨架 + 架构守卫 | 依赖方向无向上、无环 |
| M1 | 协议 + 会话持久化 | Op→Event 回放确定性；JSONL 可重建 |
| M2 | 沙箱 × 审批双轴 | 5×3 矩阵自洽；OS 沙箱三平台可用 |
| M3 | 工具层（Shell-First + apply_patch） | 文件变更 100% 走 patch 信封 |
| M4 | Goal 引擎（Plan→Code→Review→Learn） | 断点恢复；长程任务不丢上下文 |
| M5 | TUI 宿主 | 快捷键与 slash 命令对齐 Codex |
| M6 | Web 宿主 | 与 TUI 消费同一事件流，无业务逻辑重复 |
