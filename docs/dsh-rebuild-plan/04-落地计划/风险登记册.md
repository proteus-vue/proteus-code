# 风险登记册

| # | 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|---|
| **R1** | **Rust 编译慢放大"AI 调试慢"**（本项目已确认痛点） | 高 | 高 | ① 业务逻辑纯函数化，`cargo test` 秒级验证不启动 agent；② 高频改动放 `dsh-protocol`（零依赖、编译最快）；③ JSONL 回放测试不依赖真实模型；④ 提前配 sccache / 分离 rust-analyzer target dir |
| **R2** | **AI 写 Rust 一次通过率低于 TS** | 高 | 中 | ① 内核 trait 先定稳，AI 只填实现；② 给 AI 提供完整 trait 签名上下文；③ 优先让 AI 写 L3/L5（约束少），L2 人工把关 |
| **R3** | 上游 DSH 破坏性变更 | 高 | 中 | NEO 是重写非 fork，不双向同步；只单向借鉴设计；冻结 `0.1.0-rc.6` 快照作行为基线 |
| **R4** | OS 沙箱在目标平台不可用 | 中 | 高 | fail-closed（拒绝执行而非裸奔）；**M2 就要实机验证三平台**，不要拖到最后 |
| **R5** | Windows 沙箱限制（读取/网络/进程可见性不受限） | 高 | 中 | 文档诚实标注；Windows 上推荐 WSL2 走 Linux 沙箱 |
| **R6** | 协议过早冻结，后期改动成本高 | 中 | 高 | `#[non_exhaustive]` + `Unknown` 兜底；事件带 `schema_version`；M1 多用例压测 |
| **R7** | 固定内核导致将来某需求无法扩展 | 低 | 中 | ADR-0001 已评估：4 类扩展点覆盖绝大多数需求；真需要时改内核（接受此代价） |
| **R8** | 提示词缓存命中率不达 60% | 中 | 中 | 固定前缀字节稳定是硬要求；M0 就把工具描述顺序固定下来并加测试 |
| **R9** | 长程 Goal 任务 token 成本失控 | 中 | 中 | 五项停止条件 + token 预算 500K；进度面板实时显示消耗 |
| **R10** | 团队 Rust 上手慢 | 中 | 中 | 预留 2–4 周 ramp；先让前端同学写 L5，逐步接触 L2 |
| **R11** | 沙盒环境无 Rust 工具链导致原型未编译验证 | **已发生** | 中 | 本包内 `cargo check` 未执行；**本地首次打开必须先跑** `cargo check --workspace`；把错误反馈回来修正原型 |
